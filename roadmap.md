# Roadmap

- [x] Had navigasi dan topeng peta seluruh Semenanjung Malaysia dengan garisan sempadan Selangor
- [x] Nota untuk stesen di luar Selangor (Jambatan Sulaiman, Tanjung Malim)
- [x] Petunjuk legenda pada peta: sempadan negeri dan stesen dalam/luar sempadan
- [x] Nama empangan, bacaan paras sungai dan warna status biru/kuning/oren/merah
- [x] Ikon stesen (pin bergelembung gelombang) pada petunjuk dan peta; berputus-putus untuk stesen luar sempadan
- [x] Ikon dan petunjuk empangan, kapasiti maksimum serta anggaran isi takungan setiap empangan
- [x] Hapus garisan pada semua pulau Selangor dan tukar garisan sempadan tanah besar kepada hijau pekat
- [x] Buang pilihan Hijau hutan dan gunakan garisan sempadan hijau muda untuk Biru malam
- [x] Tambah maklumat tali air utama Selangor dan saliran berisiko penuh dengan status simulasi yang jelas
- [x] Susun petunjuk status takungan mengikut warna biru, kuning, oren dan merah
- [x] Masa senario dan kesan simulasi faktor laut pada saliran terpilih
- [x] Jadual rasmi PHN Pelabuhan Klang mengikut masa MYT (liputan hari ini dan dua hari berikutnya)
- [x] Butang muat semula semua sumber rasmi dengan status dan masa setiap sumber
- [x] MET: ramalan 7 hari; LUAS: 6 empangan; JPS: cerapan hujan dan saliran, serta 4 stesen sungai sepadan — data peta tanpa padanan kekal contoh berlabel
- [x] Ganti topeng kelabu dengan biru laut lembut dan paparkan laut sekitar Semenanjung
- [ ] Tanda hotspot banjir rasmi JPS pada peta Selangor dengan sumber dan masa data
